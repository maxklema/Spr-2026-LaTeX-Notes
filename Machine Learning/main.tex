\subsection{Learning Methodology}
\vspace{11pt}

It is important to learn from examples. Machine learning is all about "learning from the data". It is also important to compare with something you are familiar with. For example, when picking up C language after knowing another language, like Java, or C\#, or C++, it is easier than learning it as your first language. In deep learning, transfer learning is when you build a model for one task and then use it for another task. It can be expensive, takes a lot of money, but once you have one model for a certain task, you can use it for another task using transfer learning.

It is also important to get your "hands dirty" and try out new projects through trial and error. In machine learning, this is known as reinforcement learning - try to get the agent to do something, and if it fails, give it a penalty to try something else until it "succeeds" or "learns".

Reading books or papers can be very helpful. Same thing with university lectures, too. 

Additionally, you should work with someone who is smarter than you, someone you can look up to and learn from who has been in your shoes before. 

Throughout the whole learning process, it is important to reflect and take notes: what are mistakes to avoid in the future? What are good practices to keep? Applying AI tools can help with the process, too, as long as you use them with caution.

\vspace{11pt}
\textbf{In General, there are two learning methods}:
\begin{itemize}
    \item Learning by instruction - Have a detailed example and instruction you can follow to learn the basics.
    \item Learning by discovery - important to pivot to eventually, no clear direction or example to follow through.
\end{itemize}
\vspace{11pt}

In Software development, you must have the ability to find the answer to a question/problem/issue quickly. Similarly, it is critical to have the ability to learn how to find the answer quickly and the ability to ask good questions.

\vspace{11pt}
\textbf{Differences from C Programming Language}
\vspace{11pt}

\begin{itemize}
  \item C is strongly typed; Python is weakly typed.
  \item Python is historically interpreted; C is compiled.
  \item \textbf{No main function in Python.}
  \item C requires manual memory management; Python manages memory for you.
  \item \textbf{Python uses indentation; C uses curly braces.}
  \item \textbf{C uses semicolons; Python does not.}
  \item \textbf{C is procedural (not OOP); Python is OOP.}
  \item Python reads more like English than C.
  \item \textbf{There are no "do ... while" loops in Python}
  \item \textbf{Variable scope within a function: Python variable scope is local to a function (while/for/if statements do not create a new scope) while C local to a block.}
  \item \textbf{Exception handling: In C, everytime you call a function, you check some variable and return a error code. In Python, you can use try and except.}
  \item \textbf{Passing an object in Python is similar to pass by reference, while passing in an int, float, etc is pass by variable (value).}
\end{itemize}

\vspace{11pt}
\textbf{Language Features or Topics}
\vspace{11pt}

The paradigm of a language is important to consider. Is it OOP, procedural, functional, etc? Additionally, are variables weak/strong typed, static or dynamic? For conditional branches, how do if/else, while, and for statements work?

For functions, are these pass-by-value, pass-by-pointer, etc? How do return types work, what about recursive functions, default parameters, etc?

What are popular libraries in the language? 

What are the build-in data types (int, double, char, string, etc.) What about advanced data types and structures (struct, pointers, list, tuple, dictionary, etc.).

What about I/O (file, socket, etc), memory management, and debugging and the IDE?

In many AI models, a higher \textbf{temperature} means a more "randomized" output, whereas a lower temperature means a more predictable output.

The following demo uses gradio as a GUI library and Google's genai library to create a grammar fixer:

\vspace{11pt}
\begin{lstlisting}[language=Python, breaklines=true]
from google import genai
from google.colab import userdata
from google.genai.types import GenerateContentConfig
import gradio as gr # Moved import here to be consistent with other imports

client = genai.Client(api_key=userdata.get('GEMINI_API_KEY'))
prompt_for_summarization = "Please correct the following sentence with proper spelling, grammer, and punctuation."

# function to reset the conversation
def reset() -> list:
    return []

# function to call the model to generate
def interact_summarization(prompt: str, article: str, temp = 1.0) -> list[tuple[str, str]]:
    '''
    * Arguments

      - prompt: the prompt that we use in this section

      - article: the article to be summarized

      - temp: the temperature parameter of this model. Temperature is used to control the output of the chatbot.
              The higher the temperature is, the more creative response you will get.

    '''
    input = f"{prompt}\n{article}"

    response = client.models.generate_content(
      model="gemini-3-flash-preview",
      contents=input,
      config=GenerateContentConfig(
        temperature=temp,        # creativity / randomness
        max_output_tokens=2000,  # cap on response length
      ),
    )

    # Check if the response has choices and if the first choice has a message and content
    if response.candidates and response.candidates[0].content and response.candidates[0].content.parts:
        return [(input, response.candidates[0].content.parts[0].text)]
    else:
        return [(input, "No summary could be generated.")]

# this part generates the Gradio UI interface
with gr.Blocks() as demo:
    gr.Markdown("# Part1: Summarization\nFill in any article you like and let the chatbot summarize it for you!!")
    chatbot = gr.Chatbot()
    prompt_textbox = gr.Textbox(label="Prompt", value=prompt_for_summarization, visible=True)
    article_textbox = gr.Textbox(label="Article", interactive = True, value = "helo hw r u?")
    with gr.Column():
        gr.Markdown("#  Temperature\n Temperature is used to control the output of the chatbot. The higher the temperature is, the more creative response you will get.")
        temperature_slider = gr.Slider(0.0, 2.0, 1.0, step = 0.1, label="Temperature")
    with gr.Row():
        sent_button = gr.Button(value="Send")
        reset_button = gr.Button(value="Reset")

    sent_button.click(interact_summarization, inputs=[prompt_textbox, article_textbox, temperature_slider], outputs=[chatbot])
    reset_button.click(reset, outputs=[chatbot])

demo.launch(debug = True)
\end{lstlisting}

\textbf{Artificial Intelligence, Machine Learning, and Deep Learning}
\vspace{11pt}

Artificial Intelligence $\to$ Machine Learning $\to$ Deep Learning. AI is the largest and contains all other topics inside of it.

\vspace{11pt}
So, what is \textbf{Artificial Intelligence (AI)}? AI was born in the 1950s (around 70 years ago) and is defined as the effort to automate intellectual tasks normally performed by humans. It is not necessarily related to learning (as in machine learning). But, for a long time, people did not focus on machine learning. Instead, AI consisted of hard-coded rules by programmers (symbolic AI). 

\vspace{11pt}
What is \textbf{Machine Learning (ML)}? According to Andrew Ng, ML at its basic form is trying to find an unknown target function $f: x \to y$. For example, given $x$ and $y$ (target, label, or answer), what is the mapping or relationship between the variables? An ML system is trained rather than explicitly programmed. 

In classical programming, given rules and data, you find out what the answer or result is. But instead, in ML, given the data and answers, we want to figure out the rules. It is the other way around.

In many cases, ML models are all about finding appropriate representations for their input data --- transformations of the data that make it more amenable to the task at hand. Learning describes an automatic search process for data transformations that produce useful representations of some data, guided by some feedback signal (real answer, label) --- representations that are amenable to simpler rules to solve the task at hand.

\vspace{11pt}
What is \textbf{Deep Learning (DL)}? DL is a specific subfield of ML. A new take on learning representations from data that emphasizes learning successive layers of increasingly meaningful representations. For example, using an N-layer Neural Network to recognize numbers 0-9.

\vspace{11pt}
\subsection{Types of Machine Learning}
\vspace{11pt}

There are five major categories:
\begin{itemize}
    \item Supervised learning
    \item Unsupervised Learning
    \item Semi-supervised learning
    \item Self-supervised Learning
    \item Reinforcement Learning
\end{itemize}

\newpage
\textbf{Supervised Learning}
\vspace{11pt}

The training set fed to the machine learning includes the desired solutions, called labels. It is sort of like "learning with a teacher". This is going to be our main focus. For example, spam classification. You provide the model with sample emails and tell the model whether it is spam or not spam. Then, give it a new instance and see what it predicts.

\vspace{11pt}
\textbf{Unsupervised Learning}
\vspace{11pt}

The training data is unlabeled. The system tries to learn without a teacher. This can still be very important. For example, we have a training set of people who belong to different groups, so the model can try to group the people into different clusters.

\vspace{11pt}
\textbf{Semi-supervised Learning}
\vspace{11pt}

The training data are partially labeled. Some input data is labeled, and some other data is not labeled.

\vspace{11pt}
\textbf{Self-Supervised Learning}
\vspace{11pt}

A model is trained on a task using the data itself to generate supervisory signals, rather than relying on external labels provided by humans. A popular example is ChatGPT training. Text solitaire may include the word 'I', then the model will output 'like', then 'like' is followed by 'machine', then 'learning', and so on and so forth. ChatGPT gets this data from the internet. They try to predict the next token.

It is self-supervised learning because all the input data also contains the output labels.

\vspace{11pt}
\textbf{Reinforcement Learning}
\vspace{11pt}

The learning system, called an agent in this context, can observe the environment, select and perform actions, and get rewards in return (or penalties in the form of negative rewards). It must then learn by itself...

For example, should the agent touch the water or the fire? If the agent tries to touch the fire, it gets a negative reward (-50 points). Then, next time, the agent will know that the fire is bad and will avoid it.

\vspace{11pt}
\textbf{Outputs}
\vspace{11pt}

There are two types
\begin{itemize}
    \item Classification --- Predict a class (e.g., digits 0, 1, ..., 9). Usually, finite classes.
    \item Regression --- Try to predict a value (e.g., house prices). Can be infinite.
\end{itemize}

\subsection{Key Components for Machine Learning}
\vspace{11pt}

\begin{center}
    \includegraphics[width=0.6\textwidth]{10.jpg}
\end{center}
\vspace{11pt}

A large part of machine learning is finding the correct weights and parameters to optimize some unknown target function $f$, as we mentioned when describing what machine learning was.

A good way to visualize this is with supervised learning through a linear regression model. In a linear regression model, we have a collection of $(x_n,y_n)$ points. Our goal is to find a target function $y=ax+b$, where $a$ and $b$ are our weights. \textbf{Given any input $x$, we want to predict the output $y$.} We want to optimize these weights through training to build the most accurate model. We first start with random $a$ and $b$ weights, since we do not really have a good estimate.

\vspace{11pt}
\begin{center}
    \includegraphics[width=0.4\textwidth]{11.png}
\end{center}
\vspace{11pt}

We start with these random weights $a$ and $b$, and using real input data $x_i$, we compute $\hat{y}=a_0x_i+b_0$. After computation, we will compare all $\hat{y}$ with $y_n$, which represents the actual expected output value given $x_n$. We can use a formula called the mean sqaure error (MSE) to calculate the difference between the expected $y_n$ value and the value that the model predicted, $\hat{y}$.

\vspace{11pt}
\begin{center}
    $MSE = \frac1n\Sigma_{i=1}^n(\hat{y}_i-y_i)^2$
\end{center}
\vspace{11pt}

We can also use another (more common) error calculation formula called Root Mean Square Error (RMSE), which is the square root of MSE:

\vspace{11pt}
\begin{center}
    $RMSE = \sqrt{\frac1n\Sigma_{i=1}^n(\hat{y}_i-y_i)^2}$
\end{center}
\vspace{11pt}

RSME can also be called our \textbf{loss function}, and represented by the variable $g$. In machine learning, a loss function, like RSME, measures the error between the model's predicted output and the true output.

Using this loss function, we then go through an optimization process of updating our weights (in the example, $a$ and $b$) to (hopefully) make the target function $f$ that we are trying to model more accurate. One way to achieve this is through a process called \textbf{gradient descent}. Essentially, gradient descent is the process of finding the derivative of our weights relative to the loss function and applying a learning rate ($lr$) to update the weight. The goal is to find a minimum value for the loss function to optimize the model.

\vspace{11pt}
\begin{center}
    \includegraphics[width=0.4\textwidth]{12.jpeg}
\end{center}
\vspace{11pt}

A general gradient descent optimization function may look something like

\vspace{11pt}
\begin{center}
    $a_n=a_{n-1}-\frac{\partial g}{\partial a}|_{a=a_{n-1}} * lr$

    $b_n=b_{n-1}-\frac{\partial g}{\partial b}|_{b=b_{n-1}} * lr$
\end{center}
\vspace{11pt}

\begin{aside}
    \textbf{Note}: We use a partial derivative $\partial$ because the loss depends on more than one weight (in this case, it depends on both $a$ and $b$).
\end{aside}
\vspace{11pt}

After some amount of trials, the parameters will be minimized. How do you know this? You can repeat the training for some large $N$ number of iterations or create a tolerance $TOL$ where the training concludes when the descent of each iteration is below some $TOL$ value.

In the end, machine learning depends on 3 components:
\begin{itemize}
    \item 1) What are the weights/parameters to be optimized?
    \item 2) What is the Loss function?
    \item 3) Optimization --- Update the weights/parameters to minimize the loss function.
\end{itemize}
\vspace{11pt}



\subsection{End-to-End Machine Learning Project Steps}
\vspace{11pt}

When consider an end-to-end machine learning project, there are six main steps:
\begin{itemize}
    \item 1) Look at the big picture
    \item 2) Get the data.
    \item 3) Discover and visualize the data to gain insights.
    \item 4) Prepare the data for ML algorithms.
    \item 5) Select and train an ML model.
    \item 6) Evaluate on the test set.
\end{itemize}
\vspace{11pt}

\newpage
\textbf{Looking at the Big Picture}
\vspace{11pt}

Let's say we are given the problem to predict the median housing price in any district, given all the other metrics (location, number of bedrooms, population, etc.). The first step is to frame the problem: What is exactly the business objective? What does the current solution look like (if any)? Is it supervised, unsupervised, or reinforcement learning? Is it a classification task, a regression task, or something else?

We also want to select a performance measure (such as RMSE). Another potential performance measure (loss function) is the mean absolute error (MAE), defined as

\vspace{11pt}
\begin{center}
    $MAE(X,h) = \frac1m\Sigma_{i=1}^m|h(x^{(i)})-y^{(i)}|$
\end{center}
\vspace{11pt}

It is also important to check the assumptions -- listing and verifying the assumptions that have been made so far as this can help you catch serious issues early on.

\vspace{11pt}
\textbf{Get the Data}
\vspace{11pt}

A lot of times, you can download the data from the Internet. It is important once you find a data set to take a quick look at the data structure and create a test set (i.e. 80\% for training and 20\% for testing).

\vspace{11pt}
\textbf{Discover and Virtualize the Data to Gain Insights}
\vspace{11pt}

This step includes virtualizing data, looking for data correlations and independence between variables, and experimenting with attribute combinations.


\vspace{11pt}
\textbf{Prepare the Data for ML Algorithms}
\vspace{11pt}

Before we can train the model on our data, we need to prepare the data. It is important to check if there is any missing data or if any data needs cleaning. Additionally, it should be checked if the data is categorical data (e.g., car type instead of numerical) as that can influence training approaches. Feature scaling (rescaling numeric input features so they are on comparable ranges) and transformation pipelines (a sequence of preprocessing steps and a model, chained together into one object) should also be considered.

\vspace{11pt}
\textbf{Select and Train an ML Model}
\vspace{11pt}

Cross-validation is the process of spiting the training data into several folds (for example, 5 parts). You train and evaluate the model multiple times, each time using a different fold as validation and the rest as training. Averaging these results gives a more reliable estimate of how well the model will generalize, and helps you compare different models or hyperparameters more fairly.

Fine-tuning the model occurs after choosing a model family (like linear regression, random forest, neural network) and adjusting its hyperparameters (like the learning rate) to improve performance. Cross validation is usually used here to decide which settings work best without overfitting.

Lastly, analyzing the model (important features) is the process of inspecting the model to understand how its making predictions. This often includes looking at which features are most important for the model's decisions. For example, in a housing price model, you might find that median income or location are the most influential features. This gives insight into the problem, helps check for issues (like relying on the wrong signals), and can guide future feature engineering.

\vspace{11pt}
\textbf{Evaluate on the Test Set}
\vspace{11pt}

\textbf{Do not use the test set for model selection.} A test set should be used only once at the very end to estimate how well your final chosen model will perform on truly unseen data.

If you do, the test set effectively becomes part of the training and selection process, and you will overfit to the test set: your reported performance looks great on that specific test data but is too optimistic and will not generalize as well to new real-world data.

\boldsecbottom{Categorical Data}

What do we do with non-numeric data? We can enumerate it. We can assign $1,2,\dots,n$ to different strings. However, doing this makes an assumption that low is 1, middle is $n/2$, and high is $n$. We call this ordinal encoding.

Another way is that we can have three columns low, med, and high, such that $[0/1, 0/1, 0/1]$. If we have $n$ categories and $n$ elements in the vector, then only one element in this vector is 1.

\boldsecbottom{Feature Scaling}

If we have some data between $0\dots10000$ and others between $0\dots100$, then these different scales can affect the results. We want to change all of these scales into a similar scale. Can we change this to between $[0,1]$? Yes.

\myeq{0 \leq \frac{x-x_{min}}{x_{max}-x_{min}} \leq 1}

With few exceptions, ML algorithms don't perform well when the input numerical attributes have very different scales. Note that scaling the target values is generally not required.

There are two common ways to get all attributes to have the same scale: min-max scaling and standardization.
\begin{itemize}
    \item Min-max scaling (\textbf{normalization}) is the simplest: values are shifted and rescaled so that they end up ranging from 0 to 1. Scikit-Learn provides a transformer called \texttt{MinMaxScaler}.
    \item Standardization: First, it subtracts the mean value (so standardization values always have a zero mean), and then it divides by the standard deviation so that the resulting distribution has unit variance. Standardization is much less affected by outliers. Scikit-Learn provides a transformer called \texttt{StandardScalar} for standardization.
    \myeq{\frac{x-x_{mean}}{\sigma}}
\end{itemize}

As with all transformations, it is important to \textbf{fit the scalars to the training data only}, not to the full dataset (including the test set). Only then can you use them to transform the training set and the test set (and new data).

    print("Mean: ", scores.mean())
    print("Standard deviation: ", scores.std())
